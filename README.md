# Bank
نظام إدارة بنك | C++

مشروع عبارة عن نظام لإدارة العمليات البنكية يعمل عبر سطر الأوامر (Console)، تم تطويره باستخدام لغة C++. يتيح النظام إدارة بيانات العملاء والمستخدمين، وتنفيذ العمليات البنكية المختلفة، مع توفير نظام صلاحيات للتحكم في وصول المستخدمين إلى وظائف النظام.

مميزات المشروع

- تسجيل الدخول باستخدام اسم المستخدم وكلمة المرور.
- نظام صلاحيات (Permissions) للتحكم في وصول المستخدمين.
- إدارة بيانات العملاء:
  - عرض قائمة العملاء.
  - إضافة عميل جديد.
  - تحديث بيانات عميل.
  - حذف عميل.
  - البحث عن عميل.
- إدارة المستخدمين:
  - عرض المستخدمين.
  - إضافة مستخدم جديد.
  - تعديل بيانات المستخدم.
  - حذف مستخدم.
  - البحث عن مستخدم.
- تنفيذ العمليات البنكية:
  - الإيداع.
  - السحب.
  - عرض إجمالي أرصدة العملاء.
- حفظ البيانات واسترجاعها باستخدام الملفات النصية (Text Files).
- تصميم البرنامج بطريقة منظمة باستخدام الدوال (Functions) والهياكل (Struct) والتعدادات (Enum).

التقنيات المستخدمة

- C++
- File Handling
- Functions
- Struct
- Enum
- Vector
- String Processing
- Console Applications

المهارات التي يبرزها المشروع

- إدارة الملفات وعمليات القراءة والكتابة.
- تصميم أنظمة تعتمد على القوائم والصلاحيات.
- تنظيم الكود وتقسيمه إلى دوال مستقلة.
- التعامل مع الهياكل (Struct) والتعدادات (Enum).
- إدارة البيانات باستخدام Vector.
- بناء تطبيقات سطر الأوامر باستخدام لغة C++.

الهدف من المشروع

يهدف المشروع إلى تطبيق مفاهيم البرمجة بلغة C++ في بناء نظام إدارة بنكي متكامل، مع التركيز على تنظيم الكود، وإدارة الملفات، وتطبيق نظام صلاحيات للمستخدمين، وتنفيذ العمليات البنكية الأساسية.

ملاحظة

تم تنفيذ هذا المشروع كأحد المتطلبات العملية ضمن دورة C++ التي قدمها الدكتور محمد أبو هدهود، بهدف تطبيق المفاهيم البرمجية التي تم تعلمها أثناء الدورة على مشروع عملي متكامل.

طريقة التشغيل

1. قم بتنزيل أو استنساخ (Clone) المشروع.
2. افتح المشروع باستخدام Visual Studio أو أي بيئة تطوير تدعم لغة C++.
3. تأكد من وجود ملفات Clients.txt و Users.txt داخل مجلد المشروع.
4. قم ببناء (Build) المشروع وتشغيله.
5. سجل الدخول وابدأ باستخدام النظام.
